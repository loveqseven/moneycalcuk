# MoneyCalcUK starter website

Static HTML/CSS/JS site suitable for free static hosting such as Cloudflare Pages, GitHub Pages or Netlify.

## Included
- Responsive homepage
- Salary / take-home pay calculator
- VAT calculator
- Profit margin calculator
- Mortgage repayment calculator
- Percentage calculator
- Age calculator
- Starter eBay, Etsy and Amazon FBA calculator pages
- Privacy and disclaimer starter pages
- SEO titles/descriptions
- Advertisement placeholders

## Before launch
1. Replace the starter privacy policy with a complete policy.
2. Review calculator assumptions and update tax/fee rules from authoritative current sources.
3. Add your domain and HTTPS.
4. Add cookie/consent tooling if required by your advertising/analytics setup.
5. Apply for AdSense after the site has useful original content and is ready for review.
6. Add affiliate disclosures where affiliate links are used.
